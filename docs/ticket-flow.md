# Ticket Flow

1. User buka panel ticket.
2. User pilih jenis ticket atau pakai quick action.
3. Bot buat channel private dengan nomor otomatis.
4. Staff bisa claim ticket.
5. Staff bisa set status order.
6. Ticket bisa ditutup.
7. Transcript disimpan ke `src/storage/transcripts`.
8. Ticket masuk ke channel log.
