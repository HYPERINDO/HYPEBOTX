# Setup Guide

1. Install Node.js 20+.
2. Jalankan `npm install`.
3. Salin `.env.example` menjadi `.env`.
4. Isi `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`.
5. Jalankan `node src/index.js`.
6. Gunakan `/setup-gamestore`.

Jika ingin deploy command manual:

```powershell
node src/deploy/deployCommands.js
```
